A one-line office joke for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/competitions/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on make.fun.

## How it works

`main.py` (standard library only) writes a single office joke to `/output/entry.txt`:

> I told my boss I'm drowning in work, so he booked a three-hour meeting with slides to discuss my workload.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
